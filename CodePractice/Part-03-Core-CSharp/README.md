# Part 3 – Core C# Concepts

Runnable examples for:
- Collections: Array, List, Dictionary, HashSet, Queue and Stack
- Generics: generic methods, generic classes and constraints
- File handling: writing, reading, directories and paths
- JSON: serialization and deserialization with `System.Text.Json`
- LINQ: filtering, projection, sorting, aggregation, grouping and joining

Run:
```bash
dotnet run --project CodePractice/Part-03-Core-CSharp/Part-03-Core-CSharp.csproj
```

Note: file examples create a `PracticeFiles` directory in the run location. The JSON examples use sample data and do not need external packages.
