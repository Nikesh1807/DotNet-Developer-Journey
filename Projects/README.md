# Projects

This folder contains complete applications built by applying concepts from the `CodePractice` section.

Create one folder per project. Each project should have:
- Its own `.csproj` file (or solution if it grows).
- A `README.md` describing the purpose, features, technologies and run instructions.
- Source code organised into meaningful folders and files.
- Screenshots or diagrams when useful.
